# TopMusic Mini App

Первый прототип Telegram Mini App.

## Что уже есть
- Главная страница
- Поиск по песням/исполнителям
- Фильтры Pop / Hip-Hop / Rock
- Избранное
- Профиль Telegram-пользователя
- Нижняя навигация
- Мини-плеер
- Telegram WebApp API
- Адаптация под телефон

## Как запустить
1. Разместите файлы `index.html`, `style.css`, `app.js` на HTTPS-хостинге.
2. Создайте бота через @BotFather.
3. Настройте кнопку Mini App и укажите URL `index.html`.
4. Откройте бота в Telegram и нажмите кнопку.

Это UI-прототип: реальные аудиофайлы и поиск по музыкальному каталогу пока не подключены.
